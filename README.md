# 🩵 シールメーカー(PuniSeal)

好きな画像をアップすると、ぷっくり3Dシール風に加工してシール台紙に並べてくれるWebアプリ。

## 遊び方
1. 画像をアップロード(透過PNG推奨・最大20枚)
2. デコ素材(星・ハート)をタップで追加/「🎲ランダム配置」で自動レイアウト
3. 台紙デザイン・ふち・ラメ加工・影などを調整
4. 「⬇️ダウンロード」で台紙PNG、「🛍️」で店頭商品風モックアップを保存

## 公開方法(GitHub Pages)
1. このフォルダの中身をそのままリポジトリにアップ
   (index.html がルート、assets/ フォルダも一緒に)
2. リポジトリの Settings → Pages → Branch を main / root に設定
3. 数分後 `https://ユーザー名.github.io/リポジトリ名/` で公開されます

ビルド不要・サーバー不要の静的サイトです。
